# poly-render

macOS generator. Links Packages/SF2Player from omr-sheet-cam (do not fork a second synth).

Bounce MIDI through SF2OfflineRenderer.render(midi:soundFont:), resample to 22050 Hz stereo, write wav + mid + json for Basic Pitch fine-tune.

SoundFont is fetched, not committed. See FONT.md when the font is chosen.
