### Expected
On failure the recorder and timer stop and the mic is released.

### Actual
The pump error handler sets `phase = .failed(...)` only. `recorder.stop()`, `stopTimer()` and clearing `onSamples` are not called, so audio capture and `streamer.append` continue (mic indicator stays on) until the session is deallocated.

### Location
`Sources/App/ListeningView.swift:107-111` (compare `stop()` :114-119 and `restart()` :210-214).
Root cause: Failure path bypasses the cleanup done in `stop()`.

### Repro
Make `streamer.pump()` throw (test double) while listening; the orange mic indicator remains on the failed screen. [RUNTIME for indicator]

Repro rate: needs device

### Severity
P2 — Privacy-visible mic left on after an error.

### Suggested fix
In the catch: `stopTimer(); recorder.onSamples = nil; recorder.onLevel = nil; _ = recorder.stop()` before setting `.failed` (share one `teardownRecording()` with `stop()`/`restart()`). Inject the recorder behind a protocol for tests.
