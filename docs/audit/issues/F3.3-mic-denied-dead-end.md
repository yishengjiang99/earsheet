**Flow:** F3 Microphone permission & session start
**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
Denied state explains and offers "Open Settings"; returning after enabling lets the user retry without leaving the screen.

### Actual
`phase = .failed("Microphone access is denied. Enable it in Settings to listen.")` renders text plus a single "Back to library" button.

### Location
`Sources/App/ListeningView.swift:61-64` and `:462-471`.
Root cause: `Phase.failed(String)` carries only text; the view cannot offer a recovery action.

### Repro
Fresh install > tap mic > Don't Allow > dead-end screen.

Repro rate: always

### Severity
P2 — Core flow dead end after one tap (mic is the main input).

### Suggested fix
Add a typed failure (e.g. `.permissionDenied`) and render "Open Settings" (`UIApplication.openSettingsURLString`) plus "Try again" on `scenePhase == .active`.

- [ ] Manual: Deny > Open Settings opens the app's settings page; enable > return > Try again starts listening.
