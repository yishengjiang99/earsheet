### Expected
Unicode titles survive; empty names fall back to a default.

### Actual
`baseName` removes everything outside `[a-zA-Z0-9-_ ]`. MIDI imports use the file name as the title (`importMIDI`), so non-Latin file names produce hidden, nameless exports.

### Location
`Sources/App/ExportView.swift:109-111`; title source `Sources/App/LibraryView.swift:240`.
Root cause: Over-strict ASCII-only sanitizer without fallback.

### Repro
Import "夜曲.mid" > Export > PDF: file is named ".pdf".

Repro rate: always

### Severity
P3 — Polish; file hidden in Files.

### Suggested fix
Strip only path-unsafe characters (`/\:*?"<>|` and control chars) using `[^\p{L}\p{N}\-_ ]`; if empty use "AI Music Radar".
