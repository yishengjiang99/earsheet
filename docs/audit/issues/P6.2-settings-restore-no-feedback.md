**Flow:** P6 Restore purchases
**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
Progress while restoring and a clear result: Pro restored / no purchase found / error with retry (matrix S10 a-c). Review notes tell App Review that Restore is also in Settings.

### Actual
Settings calls `store.restore()` and ignores the result. `ProStore.purchaseError` ("No Pro purchase found...", "Restore failed...") is only presented by an alert inside `PaywallView`; `SettingsView` has no alert, and the button does not show progress.

### Location
`Sources/App/SettingsView.swift:50-57`; alert exists only in `Sources/App/PaywallView.swift:89-97`; messages `Sources/App/ProStore.swift:149,157`.
Root cause: Feedback is coupled to the paywall view, not the restore action.

### Repro
Free account with no purchases > Settings > Restore Purchases > nothing visible happens.

Repro rate: always

### Severity
P2 — Restore reachability is an App Review point; silent failure looks broken.

### Suggested fix
Add a `RestoreResult` (restored/none/failed/cancelled) published by `ProStore.restore()`; Settings shows a ProgressView while restoring and an alert/banner for the result; reuse from the paywall.
