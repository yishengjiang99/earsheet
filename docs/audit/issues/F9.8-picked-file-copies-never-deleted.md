**Step ID:** F9.8
**Flow:** F9 Import audio / MIDI / video
**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
Temporary copies of picked files are removed after use on every path (success, error, cancel).

### Actual
`AudioImporter` uses `asCopy: true` (whole file copied, even a 500 MB file that will be rejected for length). `importAudio` and `importMIDI` never remove the URL; `importVideo` removes it only on success/generic error, not on cancellation or empty audio.

### Location
`Sources/App/ShareSheet.swift:14` (`asCopy: true`), `:73-77` (video temp); `Sources/App/LibraryView.swift:224-245,255,271-276,280-307`.
Root cause: No `defer` cleanup in the import tasks.

### Repro
Import several large files, then inspect app container `tmp/` / `Inbox`: copies remain until the OS purges.

Repro rate: always

### Severity
P3 — Storage growth; minor.

### Suggested fix
`defer { try? FileManager.default.removeItem(at: url) }` in all three import functions; consider `asCopy: false` with security-scoped access to avoid the full copy.

- [ ] Manual: After imports the temp copy is gone.
