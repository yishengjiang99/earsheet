**Step ID:** P6.4
**Flow:** P6 Restore purchases
**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
User cancel is silent; offline/other errors show plain, retryable text (S10 c/d).

### Actual
Any error from `AppStore.sync()` (including `StoreKitError.userCancelled`) becomes `"Restore failed: \(error.localizedDescription)"` and a failure telemetry event.

### Location
`Sources/App/ProStore.swift:147-152`.
Root cause: Single catch without distinguishing `StoreKitError.userCancelled`/network.

### Repro
Signed-out sandbox/Xcode env > Restore > cancel the Apple ID prompt > alert with raw text. [RUNTIME]

Repro rate: needs device/sandbox

### Severity
P2 — Misleading error for a normal user action.

### Suggested fix
`catch StoreKitError.userCancelled` -> return false, no alert, telemetry result `cancelled`; `StoreKitError.networkError` -> "Couldn't reach the App Store. Check your connection and try again."; default -> generic friendly text.
