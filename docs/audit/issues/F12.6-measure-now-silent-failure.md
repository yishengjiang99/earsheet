**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
Permission is requested/handled; failure shows a message; a denied mic never stores a bogus noise floor.

### Actual
`measureFloor()` starts an `AudioRecorder` directly. If `start()` throws the catch only resets the spinner. With permission denied iOS delivers silent buffers (inferred), so a near-zero floor can be saved and then drives the auto gate threshold.

### Location
`Sources/App/SettingsView.swift:195-208`.
Root cause: No permission check or error surface in the helper.

### Repro
Deny mic > Settings > Measure now > spinner then nothing/odd value. [RUNTIME]

Repro rate: needs device

### Severity
P2 — Silent failure and potentially bad gate settings that hurt transcription.

### Suggested fix
Check `AVAudioApplication`/`AVAudioSession` record permission first (request if undetermined, message if denied); show an alert on start failure; do not persist the floor when peak is ~0.
