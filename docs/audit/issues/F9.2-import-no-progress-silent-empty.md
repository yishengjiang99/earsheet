**Step ID:** F9.2
**Flow:** F9 Import audio / MIDI / video
**Static verdict from audit:** GAP (static code read; `[RUNTIME]` items need a device)
**Build / env:** main @ `0dba134` · iOS 17+ · Simulator/Device · StoreKit env: Xcode config (`Products.storekit`) · n/a Apple ID

### Expected
Immediate "Transcribing…" progress with Cancel while decoding + inference runs; a file with no audio gets a message.

### Actual
After the picker closes nothing on screen changes while `importAudio`/`importVideo` decode and run the Core ML transcriber (seconds for a 60 s file). There is no `isImporting` state. `guard !samples.isEmpty else { return }` ends silently. A second import cancels the first without telling the user.

### Location
`Sources/App/LibraryView.swift:248-308` (no progress state), `:256` and `:287` (silent empty), `:249,:281` (silent supersede).
Root cause: Import tasks have no UI state.

### Repro
Import a 55 s file: Library looks idle for several seconds; then a take appears. Import a silent file: nothing ever happens.

Repro rate: always

### Severity
P2 — Looks hung; users re-tap and cancel their own import.

### Suggested fix
Add `@State isImporting` with a blocking overlay (`ProgressView("Transcribing…")` + Cancel that cancels `importTask`); post "No audio found in that file." on empty samples; disable import buttons while busy.
