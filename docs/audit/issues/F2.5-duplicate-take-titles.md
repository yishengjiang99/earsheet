### Expected
Default titles are unique.

### Actual
Title = `"Take \(takes.count + 1)"` in both `addTake` and the held-take path, so deleting "Take 2" of three and recording again yields a second "Take 3".

### Location
`Sources/App/TakeLibrary.swift:96`; `Sources/App/ListeningView.swift:173`.
Root cause: Count-based numbering.

### Repro
Record 3 takes > delete "Take 2" > record again: two rows named "Take 3".

Repro rate: always

### Severity
P3 — Polish; ambiguous rows and export file names.

### Suggested fix
Use next number = max numeric suffix among takes + 1 in a single helper used by both sites.
