### Expected
A Cancel/close control during warm-up and listening that discards audio, saves nothing and returns to the Library (confirm if more than a few seconds were captured).

### Actual
The full-screen cover has no close button. While `.preparing` there is no control; while `.listening` only Stop. Stop with audible sound always creates a take (or a held take at the limit).

### Location
`Sources/App/ListeningView.swift:277-313` (toolbar has only held-take back and debug Export), `:280-283` (preparing), `:383-394` (Stop only), `:183-187` (always saves).
Root cause: Session lifecycle has no cancel transition.

### Repro
Tap mic by accident > wait: no way back until Stop; Stop with ambient noise may save "Take N".

Repro rate: always

### Severity
P2 — Accidental taps burn a free slot or leave the user stuck during model warm-up.

### Suggested fix
Add a leading toolbar "Cancel" in `.preparing`/`.listening`: stop recorder + timer, drop samples (no WAV, no take), dismiss. Confirmation dialog if elapsed > 5 s.
