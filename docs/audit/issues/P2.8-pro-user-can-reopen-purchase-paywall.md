### Expected
A Pro user sees plan status and a Manage Subscription entry, never a buy CTA (Lifetime on top of a subscription, or monthly while yearly).

### Actual
The row shows "You have Pro" with a checkmark but is still a button that presents `PaywallView`; `PaywallView` never reads `isPro`, so all three plans and the CTA are purchasable.

### Location
`Sources/App/SettingsView.swift:32-48,159-161`; `Sources/App/PaywallView.swift:13-15` (no Pro state).
Root cause: No Pro branch in either the Settings row or the paywall.

### Repro
Buy any plan > Settings > Go Pro > paywall with Buy CTA is shown.

Repro rate: always

### Severity
P2 — Risk of accidental double charge; misleading with workaround.

### Suggested fix
When `store.isPro`: row shows plan status and opens `AppStore.showManageSubscriptions(in:)` (or `.manageSubscriptionsSheet`); `PaywallView` shows a "You're Pro" state if reached. Detail enhancements in [P9.4].
